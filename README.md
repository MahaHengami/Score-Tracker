🎳 Score Tracker:

A simple and interactive web application to track scores. This project allows users to increment a counter and save their previous scores to keep a running history. 

 Features
- Increment Button: Adds +1 to the current score.
- Save Button:Saves the current score to the history log and resets the counter to 0.
- Visual Theme: Custom bowling-themed background and responsive UI.

 Build with:
- HTML5: For the structure of the application.
- CSS3: For styling, colors, and layout.
- JavaScript (Vanilla): For the counter logic and DOM manipulation.

 How to Run:
1. Clone this repository to your local machine.
2. Open the project folder in your code editor (like VS Code).
3. Open the `index.html` file in your browser, or use an extension like Live Server to view it.

 What I Learned:
Through this project, I practiced working with the Document Object Model (DOM), writing clean JavaScript functions, and handling simple state variables.
